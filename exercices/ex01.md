## Lister les entrées


### Lister les entrées du dictionnaire Trévoux

La fonction `doc()` permet de charger un fichier XML à partir d’un chemin. De la même façon, la fonction `collection()` charge une collection de fichiers XML à partir d’un chemin.

La clause `let` permet d’affecter une variable au résultat de l’expression XPath.

```xquery
    let $docs := collection("../data/Garcia-Rodriguez")
    return $docs//*:body/*:entry
```

```xquery
    declare namespace tei = "http://www.tei-c.org/ns/1.0";

    let $docs := collection("../data/Garcia-Rodriguez")
    return $docs//tei:body/tei:entry/tei:form/tei:form
```

Comment lister seulement les vedettes orthographiques (`orth`) ?

## Lister les entrées triées par ordre alphabétique

```xquery
    declare namespace tei = "http://www.tei-c.org/ns/1.0";
  
    let $data := 
        for $vedette in collection("../data/Garcia-Rodriguez")//tei:body/tei:entry
            order by $vedette/(tei:form/tei:form/tei:orth)[1]
            return $vedette
    return $data//tei:form/tei:form/tei:orth
```

avec fn:sort()

```xquery
    declare namespace tei = "http://www.tei-c.org/ns/1.0";

    let $docs := collection("../data/Garcia-Rodriguez.xml")
    return sort($docs//tei:body/tei:entry/tei:form/tei:form/tei:orth)
```
## lister les entrées

- compter les entrées par lettre
```xquery
declare namespace tei = "http://www.tei-c.org/ns/1.0";

    for $entry in $docs//*:body/*:entry//*:orth[1]
        let $initial := substring($entry, 1,1)
        order by $entry
        group by $initial
    return ("
    *************
    ", $initial, " : ", count($entry), '
    *************
    ', string-join($entry/text(), '
    '))
```
## grouper les entrées par `pos`

```xquery
  declare namespace tei = "http://www.tei-c.org/ns/1.0";
    let $docs := collection("../data/Garcia-Rodriguez")
    for $entry in $docs//*:entry[.//*:gram[@type="pos"]]
        let $pos := ($entry//*:gram[@type="pos"])[1]/@norm
        group by $pos
        order by ($entry//*:orth)[1]
    return ("
    *************
    ", fn:data($pos), " : ", count($entry), '
    *************
    ', string-join($entry/(*:form/*:form/*:orth)[1], '
    '))
```
