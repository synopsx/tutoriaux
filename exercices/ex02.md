## renvoyer du contenu par négociation de contenu sur Wikidata

À partir des entités référencées, il est possible de récupérer pour les personnes les lieux de naissance et de décès et pour les lieux les coordonnées géographiques à partir de Wikidata.

https://www.wikidata.org/wiki/Special:EntityData/Q42.rdf

https://doc.wikimedia.org/Wikibase/master/js/rest-api/#/

Personne 

date of birth (P569)
place of birth (P19)
    - coordinate location (P625) 
date of death (P570)
place of death (P20)
    - coordinate location (P625)

Place
    - coordinate location (P625) 

```sparql
SELECT ?person ?personLabel 
       ?dateOfBirth ?placeOfBirthLabel ?coordBirth
       ?dateOfDeath ?placeOfDeathLabel ?coordDeath
WHERE {
   BIND(wd:Q2105 AS ?person)   # exemple : "président de la République française"

  OPTIONAL { ?person wdt:P569 ?dateOfBirth. }
  OPTIONAL { 
    ?person wdt:P19 ?placeOfBirth. 
    OPTIONAL { ?placeOfBirth wdt:P625 ?coordBirth. }
  }
  OPTIONAL { ?person wdt:P570 ?dateOfDeath. }
  OPTIONAL { 
    ?person wdt:P20 ?placeOfDeath. 
    OPTIONAL { ?placeOfDeath wdt:P625 ?coordDeath. }
  }

  SERVICE wikibase:label { bd:serviceParam wikibase:language "fr,en". }
}
```
